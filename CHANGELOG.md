# История изменений

## 1.2.0 — 2026-10-25

- Убраны предустановленные города: список в меню состоит только из городов, которые выбрал пользователь
  (до 10, удаляются крестиком). Пока список пуст, в меню подсказка «Найдите свой город через поиск».
- Если город не выбран (первый запуск), карточка показывает «Выберите город», и сразу открывается
  список с поиском. То же — если выключить «динамическую погоду», не выбрав свой город.
- Совместимость: уже выбранный город сохраняется и попадает в список. Самые старые настройки
  с одним названием города без координат больше не распознаются — виджет попросит выбрать город заново.
- Новая панель выбора города в стиле виджета вместо системного меню: тёмная, со сглаженными углами
  и тенью, поле поиска с лупой, крупные строки «город / страна», бирюзовая точка у текущего города,
  крестик для удаления при наведении, выбор стрелками и Enter, Esc — закрыть.
  Повторный клик по названию города закрывает панель (раньше меню открывалось снова).
- В меню правой кнопки вместо подменю «Город» — пункт «Выбрать город…».
- Подсказки в том же стиле: тёмная панель со сглаженными углами и тенью, бирюзовый заголовок,
  длинные строки переносятся. Подсказки никогда не забирают фокус (из-за этого панель выбора города
  закрывалась сразу после открытия) и не показываются, пока панель открыта.
- Тесты: первый запуск без настроек, отрисовка панели выбора города и подсказки.

## 1.1.0 — 2026-10-25

### Работа при сбоях связи
- Резервный источник погоды — MET Norway: используется, если Open-Meteo не ответил.
  Ощущаемая температура считается по формуле Стедмана, часовой пояс — последний известный для города
  (или по долготе), прогноз на 3 дня собирается из почасового ряда.
- Кэш последних данных по каждому городу (до 3 дней). Без связи виджет показывает их
  с пометкой «нет связи · данные N мин назад»; в подсказке указано, если данные устаревшие или из резерва.
- При запуске сразу показывается кэш, пока загружаются свежие данные.
- Без связи — повтор каждые 2 минуты; когда сеть возвращается, погода обновляется сразу.

### Исправлено
- Настоящая причина сбоя размера окна: пока окно создаётся, у него на миг есть рамка с заголовком,
  и кадр уходил в `UpdateLayeredWindow` размером с внутреннюю часть — Windows подгоняла окно под кадр,
  и виджет «ужимался» на 18×29 пикселей (а затем по пропорциям сбивалась и высота).
  Теперь кадр выводится только у показанного окна и ровно размером с окно. Добавлен тест.

### Прочее
- Лицензия MIT.
- «О программе»: оба источника данных и лицензия.
- Тесты: разбор ответа MET Norway на настоящем примере, перевод его кодов погоды, кэш,
  цепочка источников с подменённой сетью, размер окна при запуске (273 проверки).

## 1.0.0 — 2026-10-25

Первая оформленная версия.

### Возможности
- Текущая погода с векторной анимацией: солнце, облака, дождь, снег; ночью — луна и звёзды.
- Подсказка «как ощущается»: ветер и влажность простыми словами, совет по одежде.
- Прогноз на 3 дня, раскрывается кнопкой.
- Поиск любого города мира, 6 стандартных городов России, свои города с удалением.
- «Динамическая погода»: 35 городов мира в случайном порядке, плавная смена, местное время.
- Масштаб за углы, перетаскивание, двойной клик, поверх окон, автозапуск, «О программе».

### Устройство проекта
- Код разделён на модули `src/Model`, `src/Logic`, `src/Data`, `src/UI`.
- Автотесты (`test.bat`): коды погоды, советы, разбор ответов Open-Meteo, порядок городов,
  свои города, настройки (в т.ч. старый формат и повреждённый файл).
- Иконка программы и картинки для README генерируются кодом отрисовки виджета (`tools\`).

### Исправлено
- Высота окна могла сбиваться при изменении размера и обрезать прогноз. Вероятная причина —
  кадр отдавался Windows с устаревшим размером окна (`UpdateLayeredWindow` подгоняет окно под кадр);
  теперь размер берётся у самого окна. Дополнительно высота выравнивается после любого изменения размера.
- При повторном включении «динамической погоды» первым мог оказаться город той же страны,
  что и только что показанный.
- Температура округляется «от нуля» (+2.5 → +3), а не банковским округлением.
