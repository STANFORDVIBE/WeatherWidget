# История изменений

## 1.3.0 — готовится

- Обновление в один клик: пункт меню «Обновить до версии …» скачивает архив релиза, сверяет SHA-256
  (файл `.sha256` рядом с архивом в релизе) и версию exe, подменяет exe и перезапускает виджет;
  после перезапуска у значка в трее — «Виджет обновлён до версии …». Прежний exe удаляется сам.
  Не получилось (нет связи, папка только для чтения) — предлагает открыть страницу релиза.
- Пункт меню «Проверить обновления» — не ждать суточной проверки.
- В релизе рядом с архивом — его контрольная сумма `WeatherWidget-<версия>.zip.sha256`.
- «Динамическая погода» — 100 городов вместо 35: добавлены Москва, Санкт-Петербург и другие крупные
  города России и СНГ, Европы, Азии, Африки, Америки и Океании (координаты и названия — GeoNames).

## 1.2.0 — 2026-10-29

- Чёткий виджет при масштабе экрана 125–150 %: программа помечена как DPI-aware (PerMonitorV2,
  манифест `assets\app.manifest`) и рисует в настоящих пикселях экрана. Раньше Windows растягивала
  окно как картинку, и всё было размыто. При переносе на монитор с другим масштабом карточка
  сохраняет видимый размер; панели и подсказки — тоже в масштабе своего монитора.
- Значок у часов: клик показывает виджет поверх окон (например, после Win+D), в меню — «Показать»,
  «Сбросить положение» и «Выход». В подсказке значка — город и температура.
- Только одна копия: повторный запуск exe (например, при включённом автозапуске) не открывает
  второй виджет, а показывает уже запущенный. Раньше две копии писали в один settings.txt.
- После выхода из сна погода обновляется сразу, а не через 15 минут.
- Ошибки больше не закрывают виджет молча: они записываются в `%APPDATA%\WeatherWidget\error.log`
  (одна и та же ошибка подряд — один раз; файл больше 256 КБ начинается заново).
- CI на GitHub Actions: сборка и тесты на каждый push; по тегу `v<версия>` — сборка, тесты
  и zip в релиз с описанием из CHANGELOG.

## 1.1.0 — 2026-10-29

- Английский язык интерфейса. По умолчанию — язык Windows, переключение в меню «Язык / Language»
  сразу, без перезапуска. Переведены карточка, подсказки и советы, меню, панели, «О программе»;
  дни недели, поиск городов и 35 городов «динамической погоды» — на выбранном языке.
- При смене языка переводятся и свои города, и выбранный город («Омск» → «Omsk»): через номер GeoNames,
  без связи — позже, при запуске или когда вернётся сеть. Язык названия и номер хранятся в настройках.
- Поиск города прощает опечатки: «Sidney» → Сидней в Австралии, «Londn» → Лондон, «Barselona» → Барселона,
  «Санкт-Питербург» → Санкт-Петербург. Запрос сравнивается со встроенным списком ~2800 крупных городов
  (расстояние Дамерау–Левенштейна); подсказки помечены «может, вы искали?» и работают без интернета.
- Поиск кириллицей при английском интерфейсе находит города (раньше — ничего).
- °F и mph: меню «Единицы» (°C, м/с / °F, mph); по умолчанию °F — в США (по стране из настроек Windows).
  В °F температура без плюса, как принято в США. Советы по одежде по-прежнему считаются в °C.
- Проверка обновлений: раз в сутки виджет смотрит последний релиз на GitHub и, если вышла новая версия,
  показывает первым пунктом меню «Доступна версия … — скачать». Сам ничего не скачивает.
- README на английском (README.en.md) с английскими картинками; tools\make-assets.bat рисует обе версии.
- Прогноз по часам: в раскрытой карточке — полсуток через 2 часа (время, погода, температура,
  вероятность осадков от 20 %), под ним — прогноз на 3 дня. Работает и с резервным MET Norway.
- Совет про зонт по почасовому прогнозу на 12 часов вперёд: «С 17:00 дождь (80 %) — возьмите зонт»,
  «Возьмите зонт — дождь до 16:00»; дождь с вероятностью ниже 40 % не пугает.
- Без связи несколько дней прогноз из кэша больше не показывает прошедшие дни.
- Пустое значение в ответе Open-Meteo больше не превращается в «0°» — тогда спрашиваем MET Norway.
- Настройки записываются через временный файл: сбой посреди записи не сотрёт выбранный город и свои города.
- Настройка прозрачности фона: пункт «Прозрачность…» в меню открывает ползунок в стиле виджета
  (0–100 %, колёсико и стрелки — шаг 5 %). Прозрачным становится только фон карточки — текст
  и анимация остаются чёткими. Смена города при прозрачном фоне — без «просвечивания» старого города.
- Погода не застревает на медленном сервисе: Open-Meteo и MET Norway опрашиваются наперегонки
  (запасной подключается через 3 с), дольше 12 с не ждём — дальше кэш. Лимит соединений поднят с 2 до 8.
- Смена города (выбор и динамика) показывает новый город сразу из кэша; пока идёт обновление —
  подпись «обновление…» вместо «нет связи».

## 1.0.0 — 2026-10-25

Первый выпуск.

### Погода
- Текущая погода с векторной анимацией: солнце, облака, дождь, снег; ночью — луна и мерцающие звёзды.
  Цвет фона меняется вместе с погодой.
- Подсказка «как ощущается»: ощущаемая температура, ветер и влажность простыми словами, совет по одежде.
- Прогноз на 3 дня — раскрывается маленькой кнопкой справа от времени.
- Показывается местное время города.

### Города
- Предустановленных городов нет: при первом запуске виджет показывает «Выберите город»
  и сразу открывает поиск. Выбранные города запоминаются (до 10, удаляются крестиком).
- Панель выбора города в стиле виджета: поиск по всему миру, строки «город / страна»,
  отметка текущего города, управление с клавиатуры (стрелки, Enter, Esc).
- «Динамическая погода»: 35 городов мира по кругу каждые 45 секунд, в случайном порядке,
  с плавной сменой; включается и выключается двойным кликом.

### Надёжность
- Основной источник — Open-Meteo, резервный — MET Norway.
- Кэш последних данных по каждому городу (до 3 дней): без связи виджет показывает их
  с пометкой «нет связи · данные N мин назад» и обновляется сам, когда сеть вернётся.

### Окно
- Сглаженные края и тень (окно с попиксельной прозрачностью), плавные анимации.
- Масштаб 60–250 % за любой угол, перетаскивание, «поверх всех окон», запуск вместе с Windows.
- Подсказки в стиле виджета, не забирают фокус.
- Не грузит систему: ~1–2 % одного ядра процессора, ~45 МБ памяти.

### Проект
- Код разделён на модули `src/Model`, `src/Logic`, `src/Data`, `src/UI`.
- Автотесты без внешних библиотек (`test.bat`, 283 проверки).
- Иконка и картинки для README генерируются кодом отрисовки виджета (`tools\make-assets.bat`).
