# История изменений

## Готовится

- Прогноз по часам: в раскрытой карточке — полсуток через 2 часа (время, погода, температура,
  вероятность осадков от 20 %), под ним — прогноз на 3 дня. Работает и с резервным MET Norway.
- Совет про зонт по почасовому прогнозу на 12 часов вперёд: «С 17:00 дождь (80 %) — возьмите зонт»,
  «Возьмите зонт — дождь до 16:00»; дождь с вероятностью ниже 40 % не пугает.
- Без связи несколько дней прогноз из кэша больше не показывает прошедшие дни.
- Пустое значение в ответе Open-Meteo больше не превращается в «0°» — тогда спрашиваем MET Norway.
- Настройки записываются через временный файл: сбой посреди записи не сотрёт выбранный город и свои города.
- Настройка прозрачности фона: пункт «Прозрачность…» в меню открывает ползунок в стиле виджета
  (0–80 %, колёсико и стрелки — шаг 5 %). Прозрачным становится только фон карточки — текст
  и анимация остаются чёткими. Смена города при прозрачном фоне — без «просвечивания» старого города.
- Погода не застревает на медленном сервисе: Open-Meteo и MET Norway опрашиваются наперегонки
  (запасной подключается через 3 с), дольше 12 с не ждём — дальше кэш. Лимит соединений поднят с 2 до 8.
- Смена города (выбор и динамика) показывает новый город сразу из кэша; пока идёт обновление —
  подпись «обновление…» вместо «нет связи».

## 1.0.0 — 2026-10-25

Первый выпуск.

### Погода
- Текущая погода с векторной анимацией: солнце, облака, дождь, снег; ночью — луна и мерцающие звёзды.
  Цвет фона меняется вместе с погодой.
- Подсказка «как ощущается»: ощущаемая температура, ветер и влажность простыми словами, совет по одежде.
- Прогноз на 3 дня — раскрывается маленькой кнопкой справа от времени.
- Показывается местное время города.

### Города
- Предустановленных городов нет: при первом запуске виджет показывает «Выберите город»
  и сразу открывает поиск. Выбранные города запоминаются (до 10, удаляются крестиком).
- Панель выбора города в стиле виджета: поиск по всему миру, строки «город / страна»,
  отметка текущего города, управление с клавиатуры (стрелки, Enter, Esc).
- «Динамическая погода»: 35 городов мира по кругу каждые 45 секунд, в случайном порядке,
  с плавной сменой; включается и выключается двойным кликом.

### Надёжность
- Основной источник — Open-Meteo, резервный — MET Norway.
- Кэш последних данных по каждому городу (до 3 дней): без связи виджет показывает их
  с пометкой «нет связи · данные N мин назад» и обновляется сам, когда сеть вернётся.

### Окно
- Сглаженные края и тень (окно с попиксельной прозрачностью), плавные анимации.
- Масштаб 60–250 % за любой угол, перетаскивание, «поверх всех окон», запуск вместе с Windows.
- Подсказки в стиле виджета, не забирают фокус.
- Не грузит систему: ~1–2 % одного ядра процессора, ~45 МБ памяти.

### Проект
- Код разделён на модули `src/Model`, `src/Logic`, `src/Data`, `src/UI`.
- Автотесты без внешних библиотек (`test.bat`, 283 проверки).
- Иконка и картинки для README генерируются кодом отрисовки виджета (`tools\make-assets.bat`).
