Погода — виджет для рабочего стола Windows / Weather — a desktop widget for Windows

КАК ЗАПУСТИТЬ
1. Распакуйте архив в любую папку (например, Документы\Погода).
2. Запустите WeatherWidget.exe. Установка не нужна.
3. Найдите свой город в появившемся окне поиска.

ЕСЛИ WINDOWS ПРЕДУПРЕЖДАЕТ
Программа не подписана, поэтому Windows может показать окно
«Система Windows защитила ваш компьютер». Нажмите «Подробнее»,
затем «Выполнить в любом случае».

УПРАВЛЕНИЕ
• Клик по названию города — выбрать город (поиск прощает опечатки)
• Наведение на температуру — как ощущается и что надеть
• Кнопка ⌄ у времени — прогноз по часам и на 3 дня
• Двойной клик — «динамическая погода» по городам мира
• Перетаскивание — переместить, угол карточки — размер
• Правая кнопка — меню: прозрачность, поверх окон, автозапуск,
  язык (русский / English), единицы (°C / °F), выход
• Значок у часов — показать виджет, если он потерялся за окнами;
  в его меню — «Сбросить положение» и «Выход»

--------------------------------------------------------------

HOW TO RUN
1. Unzip the archive to any folder.
2. Run WeatherWidget.exe. No installation needed.
3. Find your city in the search window that appears.

IF WINDOWS WARNS YOU
The program isn't code-signed, so Windows may show
"Windows protected your PC". Click "More info", then "Run anyway".

CONTROLS
• Click the city name — choose a city (search forgives typos)
• Hover the temperature — feels like and what to wear
• ⌄ button next to the time — hourly and 3-day forecast
• Double-click — "dynamic weather" across world cities
• Drag — move, card corner — resize
• Right click — menu: transparency, always on top, start with Windows,
  language (Русский / English), units (°C / °F), exit
• Tray icon — bring the widget back if it's lost behind windows;
  its menu has "Reset position" and "Exit"

Requires Windows 10 or 11.
